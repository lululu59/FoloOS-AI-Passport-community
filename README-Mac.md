# FoloOS Codex Mac 安装包

这个包只负责把 AI Passport 的“编程伴侣”连接到 Mac 上的 Codex，不会覆盖设备固件、番茄专注、单词熊或系统设置。

2026-08-28 v7 会自动读取终端代理和 macOS 系统 HTTP/HTTPS/SOCKS 代理，并把同一代理传递给 OpenAI 官方安装程序及其 GitHub Releases 回退下载。如果自动下载仍失败，安装程序会询问本机代理地址，例如 `http://127.0.0.1:7890`。

## 安装

1. 下载本仓库源码或源码 ZIP 并解压，不要在压缩包预览窗口里直接运行。
2. 双击 `安装与管理编程伴侣.command`。
3. 选择 `1. 一键安装或修复`。
4. 安装程序会检查 Codex CLI、登录状态、设备 Wi-Fi 和后台桥接。

Codex 账号和登录信息不能随分享包分发。若电脑没有可正常运行的 Codex CLI，安装程序会询问是否调用 OpenAI 官方安装程序；随后按浏览器提示登录即可。

## 日后换 Wi-Fi 或排错

再次双击同一个 `安装与管理编程伴侣.command`：

- 选择 2：配置或更换设备 Wi-Fi。
- 选择 3：前台启动并查看连接、录音和 Codex 传输日志。
- 选择 4：查看后台错误日志。

配置 Wi-Fi 前请用 USB 连接设备，并让 Chrome 刷机工具断开串口。设备只支持 2.4 GHz；Mac 和设备需要在同一局域网。

后台服务安装后会随 Mac 登录自动启动，正常使用不需要每次手动开桥。

首次录音时，若 macOS 询问语音识别权限，请选择允许。也可以在“系统设置 → 隐私与安全性 → 语音识别”中重新开启。

本工具只用于可信局域网，不要把桥接端口暴露到公网。
