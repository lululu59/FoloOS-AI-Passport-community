# FoloOS 源码发布记录 · 2026-09-14

本次发布为可继续开发的源码快照，包含编程伴侣、番茄专注、单词熊和系统设置。
应用采用原生 C / LVGL，与系统一起编译，没有独立应用包安装机制。

## 发布内容

- ESP32-C3 工程、四个应用、BSP、分区表、默认配置和依赖锁文件。
- 构建所需的图片 C 数组、中文字库 C 文件和 WAV；字体 OTF 及其 OFL 许可。
- Mac / Windows 桥接、安装工具源码和已有主机测试。
- `DEVELOPMENT.md` 与 `examples/app_hello.c`，说明如何在现有系统中追加应用。
- `FoloOS-source-20260914.zip` 是同一份源码的独立下载包，校验值位于仓库根目录 `SHA256SUMS.txt`。
