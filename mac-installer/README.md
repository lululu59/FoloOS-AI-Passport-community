# FoloOS 编程伴侣 Mac 图形安装器

这是面向 Apple Silicon 和 Intel Mac 的统一图形安装入口。它复用已经在真实 Mac 与 AI Passport 上验证的 v9 桥接，不重写设备协议。

## 用户操作

1. 打开 DMG，把 `FoloOS 编程伴侣.app` 拖入“应用程序”。
2. 首次是内测未公证版：在 Finder 中右键 App，选择“打开”。
3. 先点击“安装 / 修复桥接”。这一步不要求插设备。
4. 只有需要配置或更换设备 Wi-Fi 时，才插 USB 并点击“配置设备 Wi-Fi…”。
5. 点击“自定义安装应用…”，勾选番茄专注、单词熊，或都不勾选。
   界面显示对应固件的实际大小、剩余空间和相对完整版本节省的空间。
6. 点击“安装到设备”，通过已配对的 Wi-Fi 更新固件。保持设备供电和连接，
   完成后设备重启，菜单只显示所选应用以及编程伴侣、系统设置。

自定义安装不要求用户安装 ESP-IDF，也不依赖 Codex 登录状态；仍需 Python 3、
已支持无线 OTA 的社区固件，以及本机已有的无线配对信息。首次刷写官方设备
仍按根目录 INSTALL.md 操作。当前版本不提供 USB 自定义烧录。

取消勾选会从新固件中排除该应用的代码与专属素材，而不是仅隐藏菜单。
安装使用现有双 OTA 分区，不擦除 NVS，因此 Wi-Fi 设置和单词熊进度保留。
安装器会记住上次成功安装的选项；该选项不是对设备当前安装状态的实时检测。
重新勾选即可通过另一次完整固件更新装回应用。

安装前会校验镜像芯片、大小与 SHA-256；安装失败不会改用其他组合。
安装期间暂停已加载的桥接服务，结束后恢复；原先未加载的桥接不会被启动。

安装器会显示四个独立状态：可用 Codex CLI、后台桥接、设备 Wi-Fi 和设备实际连接。不再用“桥接进程已启动”代替“设备已认证连接”。

## 当前内测版边界

- App 本身是 Apple Silicon + Intel 通用原生二进制，界面使用系统 AppKit，不依赖 Swift 运行时。
- 当前内测 DMG 是 ad-hoc 签名，未使用 Apple Developer ID 公证。公开分发前还需开发者证书签名与 notarization。
- 桥接仍需 Python 3。安装器会先检测；缺少时会给出明确错误，不会虚假显示成功。真正“零依赖”公开版需在 App 内再嵌入独立运行时。
- Codex 必须已登录，且 CLI 能真正启动 `app-server daemon` 并建立本地 socket。

## 开发构建

在仓库根目录执行：

```bash
./mac-installer/build.sh
```

需要先激活 ESP-IDF **5.5.3**。脚本先构建四种固件组合，然后打包 Universal
Mac App，用户端不需要编译工具。输出 DMG 和 SHA-256 位于 `releases/custom-apps/`。
App 位于 `build/mac-installer/FoloOS 编程伴侣.app`。

仅修改 Mac 界面、且已有本次源码对应的四份固件时，可以运行
`./mac-installer/build.sh --reuse-firmware`；此模式校验已有固件但不重编译。
不要用它发布已经修改了设备源码的版本。

## 验证

- 主机测试：`python3 -m unittest discover -s tests -p 'test_*.py'`。
- 四种固件均须通过 ESP-IDF 构建，确认关闭单词熊后镜像不含其代码、词库和 WAV。
- Mac 端检查四种勾选组合的容量、取消、缺包/损坏包错误及安装失败提示。
- 真机需要另外验证四种组合的菜单、短按/长按、原有功能和 OTA 重启；
  移除后重新安装单词熊，确认学习进度保留，并确认升级后能继续下一次 OTA。
- 编译、主机测试和界面检查不能代替真机安装验证。自动测试不刷设备。
